# `src/dsa/`

Pure TypeScript **data structures and algorithms** used by the app.

## Rules

- No React imports here — UI stays in `src/app/` / `src/components/`.
- One feature (or one structure) per subfolder, e.g. `src/dsa/autocomplete-trie/`.
- Export a small, documented API; include a short note on **problem → why this DS/algorithm**.
- Prefer tests next to the module when behavior is non-trivial.

Demos will be listed in the root `README.md` as they land.
